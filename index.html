Discussion 4.7

Adding a little JavaScript to my "Hello World" page felt mundane.

So, for funsies, I linked to a simple game (demo) I built using JavaScript:Asteroid Alert!. I created this project in early 2026 as an example for the students in the Creative Computing (MULT 217) module that I lead at Saskatchewan Polytechnic.

Its primary purpose was to give the students an idea of the scope of their module final project. Its secondary purpose was to relieve the general sense of boredom I was experiencing at the time :-) The game isn't a responsive design, it could benefit from improved gameplay, and the JavaScript is a sloppy mix of procedural and OOP styles. But it works well enough for its intended purposes. It's about 900 lines of my JavaScript (plus HTML and CSS), it uses the wonderful open source JavaScript library p5.js and a few publicly available media assets.

For source code, credits and additional information, see p5js-game-demo-asteroid-alert GitHub repo. I hope you enjoy playing it!

Week 5

Discussion 5.4

For this project, I recreated a web version of the python project, Modelling the Solar System, from way back in my very first module, Fundamentals of Computing.

This web app reads from a JSON file data about the planets in our solar solar system. The 'Characteristics' checkboxes are hard-coded in HTML but the 'Planets' checkboxes are dynamically added to the HTML DOM based on data read from the JSON file. The user selects information using form controls, and the data corresponding to the selection is displayed in a form control.

The app works without a mouse (i.e. keyboard only) and it works reasonably well on a touchcreen mobile (i.e., I tested on my Pixel 7). For information about the original python project including data sources, see modelling-solar-system GitHub repo
