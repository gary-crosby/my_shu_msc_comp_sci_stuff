Discussion 4.7

Adding some JavaScript to a Hello, World! page seemed boring. Instead, I linked to a simple game (demo), Asteroid Alert!, that I built using JavaScript. I created this project in early 2026 as an example for the students in a module, Creative Computing (MULT 217), that I lead at Saskatchewan Polytechnic.

The project's primary purpose was to provide the students with an example of the scope of project that would be suitable for MULT 217's module final assessment. A secondary purpose was to proide a means to relieve the general sense of boredom I was experiencing at the time :-)

The game does not feature a responsive design, it could benefit from improved gameplay, and the JavaScript is a sloppy mix of procedural and OOP styles. But it works well enough for its intended purposes.

The game uses a wonderful open source JavaScript library, p5.js, and a few publicly available media assets. For source code, credits and other information about Asteroid Alert!, see the GitHub repo p5js-game-demo-asteroid-alert.

Happy gaming!

Week 5

Discussion 5.4

For this project, I created a web app called Solar System Explorer. This web app is an HTML + CSS + JavaScript port of a Python project, Modelling the Solar System, I originally made to fulfill the requirements of an assessment in SHU's Fundamentals of Computing. (I can't believe that was a year ago!)

The app ingests data from a JSON file containing data about the planets in our solar system. The app has checkboxes for planets and their characteristics. The checkboxes for characteristics are hard-coded in HTML; the checkboxes for planets are determined from the data in the JSON file and then dynamically added to the HTML DOM. The user selects the planet(s) and characteristic(s) that interest them. Every time the user's selections changes, the app outputs to a textarea all the data corresponding to the user's selections. The app works without a mouse (i.e. keyboard only), and it works reasonably well on a mobile phone.

For information about my original Python project including data sources, see the GitHub repo modelling-solar-system.

Discussion 5.7

An elegantly simple web app that uses an API, a form control, and the HTML DOM to display an XKCD comic . The app fetches a random XKCD comic via an API, it updates the HTML DOM to display the comic, and most importantly, it has a button so you can repeatedly fetch a new random comic.

Experience XKCD the way nature never intended: endlessly. One click becomes ten. Ten becomes a hundred. Before you know it, the sun has set, your coffee is cold, your beloved labradoodle Fifi has committed unspeakable crimes on the living room floor, and your partner waiting for you in the bedroom has begun communicating through increasingly concerned text messages. But the comics keep coming, and honestly, comic #1729 might be the next one.

You're welcome.

About the background photo

I took the background photo a few years ago from a roadside rest stop on Alberta Highway 6 a few kilometres north of the entrance to Canada's Waterton Lakes National Park. It's looking southward toward the Rocky Mountains which are almost entirely obscured by thick smoke from the countless forest fires that were burning in western Canada and USA. (If you look closely, you can barely make out the outline of the mountin peaks.) The day of the photo, two friends and I were planning to ride our motorcycles on Going-to-the-Sun Road in the ajoining Glacier National Park in Montana, USA. As luck would have it, early that very morning officials closed the Road to all traffic due to poor visibaility and active fires buring along the route.
