    Adding a little JavaScript to my 'Hello World' page felt too routine to me. Instead, I linked to a simple JavaScript game demo, Asteroid Attack!, I created in early 2026 for the students in the 'Creative Computing' course I lead. The goal was to create a demo of something fun that might get my students excited about the type of projects they could build within a short period of time. The game isn't mobile friendly, it could benefit from improved gameplay, and the JavaScript is a sloppy mix of procedural and OOP, but it works well enough for its intended purpose. With the exceptions of the p5.js (an open source JavaScript library) and a handful of publicly available media assets, the entire project — design, HTML, CSS, JavaScript (900+ lines) — is entirely my own. For source code, credits and additional information, go to the GitHub repo. I hope you enjoy playing it!
