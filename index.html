Instead, I've linked to a simple retro style game I made in early 2026 for my post-secondary 'Creative Computing' students. The idea was to quickly create something fun that might get them thinking about the type and scale of projects they could build in a short period of time. Anyway, I threw it together very quickly so the JavaScript is a sloppy, inefficient mix of procedural and OOP. The game isn't mobile friendly, it could use more UI work, and it could benefit from improved gameplay elements but it works well enough for the intended purpose. All the work is my own except for the open source p5.js library and a few publicly available media assets. For more information, code, and credits, go to the github repo. Enjoy!
