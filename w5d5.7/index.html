About

The XKCD comics are created by the very funny Randall Munroe. The comics are licensed under Creative Commons 2.5 Attribution-Noncommercial License so it's okay for me to reproduce them here in a non-commercial student project. The official XKCD API is a fantastic resource but it lacks CORS headers. This makes it challenging to use directly in web applications (like this one) hosted on different domains. So, instead of accessing the official XKCD API, this web app accesses this mirror which does support CORS.
